# 🎓 Student Result Management System (SRMS)

A web-based **Student Result Management System** developed as my first academic project during my Diploma in Computer Science & Technology (CST).

The system helps manage departmental academic activities digitally. It allows administrators to manage student records, teachers to upload examination marks, and students to view their academic results and access study materials.

## 🚀 Project Overview

The Student Result Management System is designed to simplify academic record management within the CST department.

Instead of managing student results manually, this system provides a centralized platform where academic information can be stored, updated, and accessed efficiently.

## ✨ Key Features

### 👨‍💼 Admin Panel
- Add and manage student records.
- Add courses and subjects.
- View student information.
- Update and delete student records.
- Manage academic information.
- Change admin password.

### 👨‍🏫 Teacher Functionality
- Access the marks entry interface.
- Upload students' subject-wise examination marks.
- Manage academic result information.

### 👨‍🎓 Student Functionality
- View individual academic results.
- Check subject-wise marks.
- Access available study materials.

## ⚙️ Installation & Setup

Follow these steps to run the project locally.

**1. Install XAMPP**

Download and install XAMPP.

**2. Clone the repository**

```bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY-NAME.git
```

**3. Move the project**

Copy the project folder into the XAMPP `htdocs` directory.

**4. Start XAMPP**

Start the following services:
- Apache
- MySQL

**5. Configure the database**

- Open phpMyAdmin.
- Create a MySQL database.
- Import the project's `.sql` database file.
- Update the database connection settings in the PHP configuration file if required.

**6. Run the project**

Open your browser and visit:

```text
http://localhost/YOUR-PROJECT-FOLDER/
```

## 🎯 Project Objective

The main objective of this project was to develop a practical understanding of web development, backend programming, database management, and CRUD operations.

Through this project, I learned how PHP interacts with MySQL databases and how a web-based application can simplify departmental academic management.

## 📚 Learning Outcomes

- Practical implementation of PHP and MySQL.
- Database creation and management.
- CRUD (Create, Read, Update, Delete) operations.
- Backend development using PHP.
- Connecting frontend interfaces with backend functionality.
- Understanding real-world academic management workflows.
